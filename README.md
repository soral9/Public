# 美容院 日程きめ

2つの候補日に対して、自分と弟がそれぞれ5段階（絶対① / ① / どっちでもいい / ② / 絶対②）で希望を出し、
どちらが①・②の日に行くかを自動で決める、1ファイルだけの静的ウェブページです。

- サーバー・データベース不要。GitHub Pages で無料公開できます。
- 状態（候補日・名前・2人の選択）はリンクの中に入っているので、LINE でリンクを送り合うだけで動きます。
- 相手には自分の選択が結果が出るまで見えません。

## 公開手順（GitHub Pages、無料）

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. **Build and deployment → Source** を `Deploy from a branch` にし、Branch を `main`（または公開したいブランチ）、フォルダを `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

## 使い方（毎月）

1. 自分がページを開き、候補日①②を入力して自分の希望を選ぶ
2. 「LINEで送る」（または「リンクをコピー」）で弟にリンクを送る
3. 弟がリンクを開いて希望を選ぶと、その場で結果が出る
4. 弟が「結果を返す」で結果リンクを自分に送る（開けば同じ結果が見える）

## 判定ルール

| 選択 | 点数 |
|---|---|
| 絶対① | -2 |
| ① | -1 |
| どっちでもいい | 0 |
| ② | +1 |
| 絶対② | +2 |

- 弟の点数 − 自分の点数 が **正** → 自分が①、弟が②
- **負** → 自分が②、弟が①
- **0（同点）** → 候補日と名前から決まるコイントスで割り当て（2人とも同じリンクを見るので結果は一致）。
  2人とも「絶対」で同じ日を希望した場合は「要相談」と表示します。
